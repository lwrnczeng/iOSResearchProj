The Flawed Code Base - refer to the .swift file.

Technical Constraints & Refactoring Requirements
Your refactored implementation must adhere to the following strict constraints:

1. Thread Isolation & Actor Bounds:

    Move the disk caching (LocalLedgerDatabase) completely off the main thread using an actor or dedicated background isolation context.

    Ensure CPU-bound decryption (decryptPayload) is executed off the @MainActor without stalling UI rendering or frame rates.

2. Combine & Concurrency Interop:

    Convert or bridge the incoming Combine reactive stream to leverage Swift Concurrency (AsyncSequence / AsyncStream or structured Task boundaries) safely.

    Eliminate all risk of memory leaks (retain cycles) inside Combine or Task operators.

3. Data-Race Safety (Swift 6):

    Ensure all models and types crossing thread boundaries conform strictly to Sendable.

    Enforce strict isolation guarantees so that UI state updates are strictly executed on @MainActor.
